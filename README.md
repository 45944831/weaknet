# WeakNet — 弱网环境模拟测试工具

一款用于 App / 网络程序弱网测试的工具：把设备流量接管到本地模拟通道，按预设场景施加**带宽限速、延迟抖动、丢包卡顿、随机断连、黑洞超时、DNS 故障、周期断网**等网络损伤，用来验证 App 在真实弱网下的表现。

支持两端：

- **Windows** — 本地代理 + 一键接管系统代理，提供 GUI（tkinter）与 CLI 两种形态，已打包 `WeakNet.exe`（GUI 版；CLI 形态用源码 `python weaknet.py` 运行）
- **Android** — 基于 `VpnService` 接管整机全部 App 流量（无需手动配代理），已打包 `WeakNet.apk`，带实时限速悬浮窗

## 快速开始

### Windows

直接运行 `WeakNet.exe`（GUI 版，图形界面）。

- 点 **「一键接管本机流量」** → 自动写入系统代理，无需手动配置
- 选择预设场景或自定义参数 → 即时生效
- 点 **「停止模拟（恢复直连）」** → 恢复，退出时自动还原系统代理

也可以从源码运行（Python 3.8+，GUI 版需要 tkinter）：

```bash
python weaknet_gui.py                # GUI 版（唯一的控制界面）
python weaknet.py                    # 无界面引擎，默认代理 8888 / 控制接口 8899
python weaknet.py --proxy-port 8888 --ctrl-port 8899
```

> **网页控制台已下线**（2026-10）：原先 Windows 与 Android 共用的 `dashboard.html` 已删除，
> 界面只保留桌面 GUI（`weaknet_gui.py`）与 Android 原生 Activity。
> 本机 HTTP 服务仍在，只 `/api/*` 供脚本/自动化调用，访问 `http://127.0.0.1:8899/` 会返回一句说明而非页面。

桌面 GUI 布局：顶部状态条带**限速总开关**（`▶ 开启限速` / `⏹ 停止限速`）、一键接管本机流量、局域网访问；其下**通栏置顶是「接管范围」**——它是「这次测谁」的开关，范围不对后面所有参数都白调，所以放在最显眼的位置；再往下左边是**场景预设 + 自定义参数**，右边是**「📱 USB 手机弱网」与事件日志**。**「🔗 环境共享」按钮在「⭐ 我的自定义」标题旁边**——共享的正是这些自定义场景，入口放在它们旁边最顺手。自定义参数默认折叠，点标题展开。

### 手机（USB 弱网，免装 APK）

Windows 端可以直接给**插在 USB 上的 Android 手机**施加弱网，手机上不需要装任何东西：

1. 手机打开「开发者选项 → USB 调试」，插上 USB 线（要能传数据），在手机上点「允许 USB 调试」
2. 界面右栏「📱 USB 手机弱网」→ 点 **「🔄 刷新设备」** → 从下拉框里选一台（多设备时）
3. 点 **「连接手机」** → 状态行显示「已接管 …」即生效，再选场景、点「▶ 开启限速」开始弱网
   （连上但没开限速时状态行会提示「当前等同直连」）
4. 测完点 **「断开」**，或直接退出程序 —— 两者都会自动把手机还原成直连，不会留下代理

原理就是两条 adb 命令：`adb reverse` 把手机的 `localhost:8888` 反向映射到电脑的代理端口，
再 `settings put global http_proxy` 让手机的系统代理指向它，流量于是顺着 USB 线进出 WeakNet。

> **写入失败怎么办（很常见）**：不少手机 —— 尤其是 Android 13+ 的国产 ROM（OPPO / ColorOS 等）——
> 禁止 adb 改写全局设置，会报 `Permission denial: writing to settings requires
> android.permission.WRITE_SECURE_SETTINGS`。这是 ROM 的限制而非 WeakNet 的问题，
> 界面会如实报错并给出替代途径，不会假装成功。可以试：
>
> 1. 开发者选项里打开 **「USB 调试（安全设置）」** 或 **「禁止权限监控」**，拔插 USB 后重试
> 2. 手机已 root：先 `adb root` 再连
> 3. 改用手写代理：手机连上与电脑相同的 Wi-Fi，在 WLAN 的代理里填电脑局域网 IP + 端口
>    （电脑这边先点「开启局域网访问」）
> 4. 或装 `WeakNet.apk` —— `VpnService` 直接接管整机流量，不需要这些权限
>
> 还有个前提要清楚：这条路径走的是**系统 HTTP 代理**，只对按系统代理走的 App 生效
> （浏览器、WebView、以及大多数用 `HttpURLConnection` / OkHttp 默认配置的 App）；
> 直连 socket 或自带代理设置的 App 不受影响。要整机无差别接管，请用 APK。

首次使用时若提示找不到 `adb.exe`，点卡片里的 **「选择 adb」** 指定它的位置（通常在 Android SDK
的 `platform-tools` 目录下），路径会记进 `weaknet_settings.json`，下次自动使用。

### Android

安装 `WeakNet.apk`（允许未知来源安装），打开后：

1. 点 **「▶ 开始弱网测试」**：一个按钮就是全部 —— **接管流量 + 按当前场景施加弱网**，首次会弹出 VPN 授权确认 → 允许；按 **「⏹ 停止弱网测试」** 断开接管，网络立刻恢复正常（场景保留，再开直接复原）
2. **「指定程序…」就在总开关旁边**（两者平级）：默认作用于全部 App；点它可切换三种范围——
   **接管一切 / 仅选中的 App / 排除选中的 App**，支持搜索、全选、清空，保存后自动重建通道生效
   （Android 靠 VpnService 按包名过滤，名单外的 App 完全不经过弱网）
3. **主界面上直接就是全部日常操作**（顶栏固定，下面整体滚动）：
   - **🎯 测试环境**：17 支内置场景按钮网格，点一下只是**选中**（选中的变蓝），不会开始限速也不会接管流量；选中内置档位后会出现 **「👀 参数：xxx」**，可查看并以它为底子另存一条自定义
   - **⭐ 我的自定义**：自定义场景网格（紫色高亮）+ **「➕ 新建 / ✏️ 编辑」**——13 项参数（带宽、延迟、抖动、丢包、随机断连、黑洞、DNS 故障、拒连、卡顿、网络切换）全都能改，保存即应用；标题旁就是 **「🔗 环境共享」**，可改本机名字、勾选局域网设备互相推送环境，别人推来同名环境进收件箱（覆盖 / 保留 / 另存，协议与桌面版一致，Windows ↔ Android 可互推）；选中自定义时出现 **「🗑 删除当前场景」**
   - **📋 事件日志**：最近 60 条连接、断连、丢包、DNS 故障、配置变更等事件（最新在上），可一键清空
4. 点右上角 **「⚙ 设置」**：悬浮二级界面里只剩**限速飘窗**一项——显示 / 收起（需授予「显示在其他应用上层」权限，App 会自动引导跳转）

App 固定竖屏，不随手机方向旋转；设置浮层点 ✕、点外部或按返回键收起。

悬浮窗实时显示：当前场景名、限速上下行、实测速率，可拖动、点主体回到 App。开始弱网测试时会自动飘出来，但**打开任何二级界面（设置 / 指定程序 / 自定义参数）时会临时收起**——悬浮窗是系统级窗口，会盖在弹窗上半部分把点击吃掉，关掉弹窗后自动恢复。

> App 端只提供「接管 / 场景 / 限速 / 飘窗」四件事；13 项自定义参数、接管范围选择、
> 环境共享请在桌面版 GUI 里配置。

## 内置场景（17 种）

| 分组 | 场景 |
|---|---|
| 常规 | 直连（无限制）、Wi-Fi 良好、4G LTE、5G（良好覆盖） |
| 弱网 | 4G 弱网（边缘/室内）、5G 弱覆盖（室内/边缘）、弱 Wi-Fi、网络拥塞、卫星链路（高延迟）、高丢包（30% 丢包）、高延迟（RTT 800ms） |
| 极端 | 高铁 / 地铁（高速移动）、电梯 / 地下室、频繁断连、黑洞（无响应）、DNS 故障、完全断网 |

> **3 支新档位（4G 弱网 / 高丢包 / 高延迟）**：补的是「速率还行但体验很差」这一档——
> 高丢包是带宽够但每三个包丢一个（视频卡成 PPT、图片加载一半），高延迟是带宽不丢包但往返
> 800ms（点了要等半天才有反应），4G 弱网是「有 4G 图标但速率塌了」的地下车库/演唱会场景。
> 三者都能用「👀 查看 / 修改参数」以它们为底子另存成自己的场景。
>
> 2026-10 清理：**2G EDGE / 2G GPRS / 56K 拨号 / 3G 已删除** —— 2G/3G 在国内外陆续退网、
> 拨号上网早已不存在，留着容易让人误以为现网还有这些档位；同时补上 **5G（良好覆盖）**
> 与 **5G 弱覆盖（室内/边缘）**。要复现「极慢网」请用自定义参数直接压带宽（例如 100 kbps），
> 不必挂靠已退网的制式。

自定义参数（13 项）：上下行带宽、基础延迟、抖动、丢包率、卡顿时长、随机断连率、黑洞超时率、DNS 故障率、周期断网开关与周期等。

### 限速总开关：启动后默认不运行

打开工具后**不会自动限制任何流量**——状态条里显示「● 未运行」，流量原样转发。必须手动开启：

| 操作 | 结果 |
|---|---|
| 点顶栏的 **「▶ 开启限速」** / APK 的 **「▶ 开始弱网测试」** | 按当前选中的场景开始限速（并接管流量） |
| **直接选一个场景 / 应用自定义参数** | **只是「选中」，不会开始限速**——选中的按钮会高亮，但流量原样转发，必须再点一次上面的开关才生效 |
| 已经在测试中时切场景 | 立即生效（不用停了再开） |
| 点 **「⏹ 停止限速」** / **「⏹ 停止弱网测试」** | 立刻恢复直连；**已选场景会保留**，下次点开启直接复原，不用重选 |

> 这条规矩是刻意改的（2026-10）：早期版本「选一个有内容的场景」就等同于开启限速，
> 结果点一下场景按钮就在没人点开始的情况下把流量限住了。现在**选场景只改「选了哪一支」**，
> 是否真的限速只认总开关。

- 状态灯同步显示「限速未开启 / 限速运行中 / 周期断网中」三态，一眼能看出有没有在限速
- Android 同样默认不动流量：**打开 App 不会自动接管**（早期版本会在启动 600ms 后自动建通道，状态栏白白挂着 VPN 图标却什么都没限），接管与限速都只由「▶ 开始弱网测试」触发；「⏹ 停止弱网测试」会同时断开接管，网络立刻恢复原样
- 接口：`POST /api/run {"enable": true/false}`，状态在 `/api/status` 的 `limit_on` 字段

### 自定义栏（⭐ 我的自定义）

调好一组参数后可以起个名字保存下来，之后像内置预设一样一键切换，不需要了就删掉：

| 操作 | 位置 |
|---|---|
| 保存 | 展开「自定义参数」→ 填名字 → 点「保存当前参数」 |
| 切换 | 点「⭐ 我的自定义」分组里的按钮即可生效（与内置档位同款样式，选中项高亮） |
| 删除 | 先选中那条自定义场景，下方才会出现「🗑 删除当前场景「名字」」按钮（有二次确认弹窗）；选内置场景时按钮自动收起。删除当前生效场景后会切回直连 |

- 自定义场景**不再单独拉一个列表**，保存后就混在「⭐ 我的自定义」分组里，和内置档位长得一样、点起来一样
- 重名自动加序号（如「地铁 5G (2)」），不会静默覆盖旧的那条
- 存储：Windows 写程序目录下的 `weaknet_presets.json`（目录不可写时自动退回 `~/.weaknet/`）；Android 存在 App 私有的 SharedPreferences 里，卸载才丢

对应接口：`GET /api/upresets`（列表）、`POST /api/upreset`（保存 / 按 id 覆盖）、`POST /api/upreset/del`（删除），应用时仍走 `/api/preset`，key 形如 `u:<id>`。

### 接管范围（二级界面）

主界面上是两个并排入口：**「接管一切」**（一键回到全部接管）和**「接管范围」**（打开二级界面勾选）。当前生效的那个会高亮并带 ✔。

只想让一部分走弱网时，点「接管范围」打开二级界面勾选：

| 模式 | 含义 |
|---|---|
| 全部接管 | 全部走弱网（此时勾选列表置灰，勾了也不生效） |
| 仅接管选定项 | 只有勾选的程序 / App 走弱网，其余走真实网络 |
| 排除选定项 | 勾选的不走弱网，其余都走 |

- 二级界面里有搜索、全选 / 清空（只作用于当前筛出来的项）、刷新，以及顶部与底部的返回按钮（Esc 同效）
- 勾选后必须点「保存」才生效；有未保存改动时点返回会先确认，放弃的改动会回滚到引擎当前值
- 「接管一切」已经生效时不再重复提交（Android 端改范围会重建 VPN 通道，重复提交会白白断一次网）
> Windows 按进程名（需该程序发起过网络连接才会出现在列表里），Android 按包名（列已安装应用）。
> 这是桌面 GUI 独有的能力，App 端不提供。

对应接口：`GET /api/targets`（候选）、`GET·POST /api/scope`（读写名单）。

### 环境共享（局域网互推环境）

同一局域网里开着 WeakNet 的机器会通过 UDP 广播自动互相发现，可以把调好的环境推给对方：

1. 点顶栏 **「🔗 环境共享」** 打开二级窗口（有未处理的环境时按钮会显示「N 条待处理」）
2. 给自己起个名字（对方看到的就是它）
3. 在「局域网里的设备」里选一台目标
4. 在「我的自定义环境」里勾选要推的场景（可多选）→ 点 **「推送给选中的设备」**
5. 对方若已有同名环境，不会静默覆盖 —— 会进对方的「收到的环境」，由对方决定**覆盖本地 / 保留本地 / 另存为…**（另存默认建议名带推送方，如「地铁3G（来自 乙）」）

- 窗口每 3 秒自动刷新设备与收件箱，**已勾选的对象不会被刷新冲掉**
- 用户名与本机标识存在 `weaknet_settings.json`；标识只生成一次，改名不会换身份（否则对方会看到幽灵设备）
- 共享端口默认 `8900`，对局域网开放，只认 `/api/hello` 与 `/api/share` 两个路径
- 发现用 UDP `18899` 起的 8 个端口：同机跑多个实例时各占一个，广播时整段都发一份
- 环境共享目前只有 Windows 桌面版，App 端不提供

对应接口：`GET·POST /api/me`、`GET /api/peers`、`POST /api/push`、`GET /api/inbox`、`POST /api/inbox/resolve`。

## 工作原理

### Windows

`weaknet.py` 是一个 `asyncio` 本地 HTTP/HTTPS 代理：

- 令牌桶双向限速（上行 / 下行独立）
- 延迟 + 抖动、丢包（表现为传输停顿，近似 TCP 重传）、随机断连（立即掐断）
- 黑洞：挂起不响应；DNS 故障：返回解析失败；周期断网：定时开关闸门
- 一键接管：写注册表 `Internet Settings` + `InternetSetOptionW` 通知生效，退出自动还原

### Android

无 Gradle，手工工具链 `javac → d8 → aapt2 → zipalign → apksigner`：

- `VpnService` 建立 tun 接口，解析 IPv4 / TCP / UDP
- 伪造 TCP 状态机（SYN-ACK、seq/ack、MSS、校验和），用 `protect()` 的 socket 转发到真实网络
- 全部限速收敛到 `vpn.write` 这一个出口，保证整机共享带宽不叠加

## 从源码构建

### Android APK

依赖：JDK 8+、Android SDK（platform + build-tools）。脚本会自动探测路径，也可用环境变量指定：

```bash
cd android
export JAVA_HOME=/path/to/jdk
export ANDROID_HOME=/path/to/android-sdk
bash build.sh
```

输出 `android/WeakNet.apk`。首次构建会自动生成自签名 keystore（`weaknet.keystore`，已被 `.gitignore` 排除）。

> 注：`android/sdk/` 与 `cmdline.zip` 是本地下载的 SDK，体积数百 MB，未纳入仓库，请自行通过 Android Studio 或 sdkmanager 安装。

### Windows EXE

需要 Python 3.8+（GUI 版需 tkinter）与 PyInstaller。仓库只发布 GUI 版包体，CLI 形态直接用源码运行即可：

```bash
python -m PyInstaller --onefile --windowed --clean --noconfirm --name WeakNet \
  --icon /abs/path/to/assets/weaknet.ico \
  --distpath . --workpath _build_gui --specpath _build_gui weaknet_gui.py
```

> 坑：PyInstaller 的 `--icon` 相对路径是相对 `--specpath` 解析的，建议直接用绝对路径。
> 网页控制台已下线，打包时不再需要 `--add-data dashboard.html`。

## 已知事项

- Android 悬浮窗权限需用户在系统设置中授予一次（App 内会引导跳转）
- Android 端需在 VPN 授权弹窗点「允许」，这是 Android 系统强制的，无法绕过
- **USB 手机弱网**依赖手机允许 adb 写入全局设置：Android 13+ 的不少国产 ROM 会拒绝
  （报 `WRITE_SECURE_SETTINGS`），此时请用界面提示里的替代途径（开发者选项中的
  「USB 调试（安全设置）」/「禁止权限监控」、root、Wi-Fi 手动代理，或改用 APK）
- USB 手机弱网走的是系统 HTTP 代理，只影响按系统代理走的 App；要整机接管请用 APK
- 桌面 EXE 是 PyInstaller 单文件打包，首次启动需解压临时文件，稍慢属正常
