# 使用说明

桌面 GUI、Android App 与 USB 手机弱网的完整操作说明，以及 17 支场景和 13 项参数的细节。

---

## 快速开始

### Windows

直接运行 `WeakNet.exe`（GUI 版，图形界面）。

- 点 **「一键接管本机流量」** → 自动写入系统代理，无需手动配置
- 选择预设场景或自定义参数只是**选中**，再点 **「▶ 开启限速」** 才开始施加弱网
- 点 **「⏹ 停止限速（恢复直连）」** → 恢复；退出程序会自动解除系统代理

也可以从源码运行（Python 3.8+，GUI 版需要 tkinter）：

```bash
python weaknet_gui.py                # GUI 版（唯一的控制界面）
python weaknet.py                    # 无界面引擎，默认代理 8888 / 控制接口 8899
python weaknet.py --proxy-port 8888 --ctrl-port 8899
```

> **网页控制台已下线**（2026-10）：原先 Windows 与 Android 共用的 `dashboard.html` 已删除，
> 界面只保留桌面 GUI（`weaknet_gui.py`）与 Android 原生 Activity。
> 本机 HTTP 服务仍在，只 `/api/*` 供脚本/自动化调用，访问 `http://127.0.0.1:8899/` 会返回一句说明而非页面。

桌面 GUI 布局：顶部状态条带**限速总开关**（`▶ 开启限速` / `⏹ 停止限速`）、一键接管本机流量、局域网访问；其下**通栏置顶是「接管范围」**——它是「这次测谁」的开关，范围不对后面所有参数都白调，所以放在最显眼的位置；再往下左边是**场景预设 + 自定义参数**，右边是**「📱 USB 手机弱网」与事件日志**。**「🔗 环境共享」按钮在「⭐ 我的自定义」标题旁边**——共享的正是这些自定义场景，入口放在它们旁边最顺手。**「场景预设」标题右侧的「！」**打开全部档位的参数与适用症状说明（见下文）。自定义参数默认折叠，点标题展开。左栏内容超出窗口高度时可滚动（鼠标滚轮或右侧滚动条），小屏上不会再有「参数被裁掉、翻不出来」。

### 手机（USB 弱网，免装 APK）

Windows 端可以直接给**插在 USB 上的 Android 手机**施加弱网，手机上不需要装任何东西：

1. 手机打开「开发者选项 → USB 调试」，插上 USB 线（要能传数据），在手机上点「允许 USB 调试」
2. 界面右栏「📱 USB 手机弱网」→ 点 **「🔄 刷新设备」** → 从下拉框里选一台（多设备时）
3. 点 **「连接手机」** → 状态行显示「已接管 …」即生效，再选场景、点「▶ 开启限速」开始弱网
   （连上但没开限速时状态行会提示「当前等同直连」）
4. 测完点 **「断开」**，或直接退出程序 —— 两者都会自动把手机还原成直连，不会留下代理
   （拔 USB 线也安全：连接时手机里装了个守护，反向端口消失后几秒内自己清掉代理）

原理就是两条 adb 命令：`adb reverse` 把手机的 `localhost:8888` 反向映射到电脑的代理端口，
再 `settings put global http_proxy` 让手机的系统代理指向它，流量于是顺着 USB 线进出 WeakNet。

> **为什么拔线要守护**：`adb reverse` 只活在 adb 会话上，拔线即断；而全局代理是写在系统设置里的，
> 拔线、重启都不会消失。不管的话手机会继续把所有请求发给一个已经没人监听的 `127.0.0.1:8888`，
> 表现为「拔了线反而上不了网」。守护用 `/proc/net/tcp` 里该端口的监听状态判断映射还在不在，
> 连续两次（间隔 2 秒）确认消失才动手，所以正常连接期间不会误清。
>
> **清理要先写 `:0` 再删**：MIUI 等 ROM 会把全局代理镜像进当前 Wi-Fi 的网络配置，
> 只 `settings delete global http_proxy` 清不掉那一份，网络校验探测照样打向旧代理，
> 手机一直显示「无互联网」（真机实测）。所以前后两端都先 `settings put global http_proxy :0`
> 让系统把网络里的代理同步清空，再删残留字段。
>
> **手机重启后**：代理写在系统设置里不会随重启消失，反向映射和拔线守护却都没了，
> 于是重启到重新点「连接手机」之间手机会短暂上不了网 —— 重连一次即可恢复。
> 手边没电脑时，用 `adb shell settings put global http_proxy :0`（或手机 WLAN 里把代理改回「无」）清掉。
>
> **端口被占用**：`adb reverse` 报 `Address already in use` 通常是手机上的 WeakNet.apk
> 正在运行 —— 它自己监听着 8888。先在手机上停掉它，或换个代理端口再连。

> **写入失败怎么办（很常见）**：不少手机 —— 尤其是 Android 13+ 的国产 ROM（OPPO / ColorOS 等）——
> 禁止 adb 改写全局设置，会报 `Permission denial: writing to settings requires
> android.permission.WRITE_SECURE_SETTINGS`。这是 ROM 的限制而非 WeakNet 的问题，
> 界面会如实报错并给出替代途径，不会假装成功。可以试：
>
> 1. 开发者选项里打开 **「USB 调试（安全设置）」** 或 **「禁止权限监控」**，拔插 USB 后重试
> 2. 手机已 root：先 `adb root` 再连
> 3. 改用手写代理：手机连上与电脑相同的 Wi-Fi，在 WLAN 的代理里填电脑局域网 IP + 端口
>    （电脑这边先点「开启局域网访问」）
> 4. 或装 `WeakNet.apk` —— `VpnService` 直接接管整机流量，不需要这些权限
>
> 还有个前提要清楚：这条路径走的是**系统 HTTP 代理**，只对按系统代理走的 App 生效
> （浏览器、WebView、以及大多数用 `HttpURLConnection` / OkHttp 默认配置的 App）；
> 直连 socket 或自带代理设置的 App 不受影响。要整机无差别接管，请用 APK。

首次使用时若提示找不到 `adb.exe`，点卡片里的 **「选择 adb」** 指定它的位置（通常在 Android SDK
的 `platform-tools` 目录下），路径会记进 `weaknet_settings.json`，下次自动使用。

### Android

安装 `WeakNet.apk`（允许未知来源安装），打开后：

1. 点 **「▶ 开始弱网测试」**：一个按钮就是全部 —— **接管流量 + 按当前场景施加弱网**，首次会弹出 VPN 授权确认 → 允许；按 **「⏹ 停止弱网测试」** 断开接管，网络立刻恢复正常（场景保留，再开直接复原）
2. **「指定程序…」就在总开关旁边**（两者平级）：默认作用于全部 App；点它可切换三种范围——
   **接管一切 / 仅选中的 App / 排除选中的 App**，支持搜索、全选、清空，保存后自动重建通道生效
   （Android 靠 VpnService 按包名过滤，名单外的 App 完全不经过弱网）
3. **主界面上直接就是全部日常操作**（顶栏固定，下面整体滚动）：
   - **🎯 测试环境**：17 支内置场景按钮网格，点一下只是**选中**（选中的变蓝），不会开始限速也不会接管流量；选中内置档位后会出现 **「👀 参数：xxx」**，可查看并以它为底子另存一条自定义；标题右侧的 **「！」** 打开全部档位的参数与适用症状说明
   - **⭐ 我的自定义**：自定义场景网格（紫色高亮）+ **「➕ 新建 / ✏️ 编辑」**——13 项参数（带宽、延迟、抖动、丢包、随机断连、黑洞、DNS 故障、拒连、卡顿、网络切换）全都能改，保存即应用；参数编辑浮层里**每行末尾都有一个「！」**，点开是这个参数的作用与坑；标题旁就是 **「🔗 环境共享」**，可改本机名字、勾选局域网设备互相推送环境，别人推来同名环境进收件箱（覆盖 / 保留 / 另存，协议与桌面版一致，Windows ↔ Android 可互推）；选中自定义时出现 **「🗑 删除当前场景」**
   - **📋 事件日志**：最近 60 条连接、断连、丢包、DNS 故障、配置变更等事件（最新在上），可一键清空
4. 点右上角 **「⚙ 设置」**：悬浮二级界面里只剩**限速飘窗**一项——显示 / 收起（需授予「显示在其他应用上层」权限，App 会自动引导跳转）

App 固定竖屏，不随手机方向旋转；设置浮层点 ✕、点外部或按返回键收起。

悬浮窗实时显示：当前场景名、限速上下行、实测速率，可拖动、点主体回到 App。开始弱网测试时会自动飘出来，但**打开任何二级界面（设置 / 指定程序 / 自定义参数）时会临时收起**——悬浮窗是系统级窗口，会盖在弹窗上半部分把点击吃掉，关掉弹窗后自动恢复。

> App 端与桌面版功能对齐：13 项自定义参数、接管范围（指定程序）、环境共享都在 App 内完成，
> 不依赖桌面版。

## 内置场景（17 种）

| 分组 | 场景 |
|---|---|
| 常规 | 直连（无限制）、Wi-Fi 良好、4G LTE、5G（良好覆盖） |
| 弱网 | 4G 弱网（边缘/室内）、5G 弱覆盖（室内/边缘）、弱 Wi-Fi、网络拥塞、卫星链路（高延迟）、高丢包（30% 丢包）、高延迟（RTT 800ms） |
| 极端 | 高铁 / 地铁（高速移动）、电梯 / 地下室、频繁断连、黑洞（无响应）、DNS 故障、完全断网 |

> **3 支新档位（4G 弱网 / 高丢包 / 高延迟）**：补的是「速率还行但体验很差」这一档——
> 高丢包是带宽够但每三个包丢一个（视频卡成 PPT、图片加载一半），高延迟是带宽不丢包但往返
> 800ms（点了要等半天才有反应），4G 弱网是「有 4G 图标但速率塌了」的地下车库/演唱会场景。
> 三者都能用「👀 查看 / 修改参数」以它们为底子另存成自己的场景。
>
> 2026-10 清理：**2G EDGE / 2G GPRS / 56K 拨号 / 3G 已删除** —— 2G/3G 在国内外陆续退网、
> 拨号上网早已不存在，留着容易让人误以为现网还有这些档位；同时补上 **5G（良好覆盖）**
> 与 **5G 弱覆盖（室内/边缘）**。要复现「极慢网」请用自定义参数直接压带宽（例如 100 kbps），
> 不必挂靠已退网的制式。

自定义参数（13 项）：上下行带宽、基础延迟、抖动、丢包率、卡顿时长、随机断连率、黑洞超时率、DNS 故障率、周期断网开关与周期等。每一项的**名字后面**都有一个 **「！」**，点开就是这个参数的作用与坑（见下）。

### 「！」场景说明（两端都有）

「场景预设 / 🎯 测试环境」标题右侧有一个 **「！」** 按钮，点开是全部 17 支档位的
**参数摘要 + 适用症状**，按「常规网络 / 弱网环境 / 极端环境」分组，当前选中的那支会标出来。

为什么需要它：光看名字分不清 ——「4G 弱网」和「弱 Wi-Fi」都是低速 + 丢包（区别在制式与重传），
「黑洞」和「完全断网」都是连不上但机制完全不同（挂住不返回 vs 立刻失败），
「高丢包」和「高延迟」都是体验差但一个是丢包重传、一个是往返慢。

内容是**只读参考**，点里面的条目不会切换场景；参数摘要由代码按档位定义现算，
改档位参数时说明会跟着变，不会出现「文档写 3 Mbps、实际早已改成 6 Mbps」。

### 「！」参数说明（逐个参数，两端都有）

自定义参数每一个**名字后面**还跟着一个 **「！」**（灰色小字、无边框，鼠标移上去才变蓝，
不抢参数名的视觉重心），点开是这个参数的说明：单位与取值范围、
它到底作用在哪一段流量上、以及最容易踩的坑。EXE 上是一个贴着按钮弹出的只读小窗
（再点同一个「！」即收起），APK 上是一个居中的悬浮小窗。

13 个参数里有一半光看名字猜不出行为，这些答案以前只能翻引擎源码：

| 疑问 | 答案（点「！」就能看到） |
|---|---|
| 「丢包率」填 30，是让请求报错还是变慢？ | 都不是 —— 表现是一段**停顿**（模拟 TCP 等重传），停多久由「卡顿时长」决定 |
| 「卡顿时长」单独填为什么没效果？ | 它只在**丢包率 > 0** 时生效，丢包率为 0 时填什么都不影响结果 |
| 「黑洞率」和「拒连率」都是连不上，差在哪？ | 黑洞是**挂住等**（转圈不停），拒连是**立刻失败**（马上走重试分支） |
| 「断连率」和「断网间隔」有什么不同？ | 断连率是随机掐**单条**连接，断网间隔是**周期性整体断网**，两项可以叠加 |
| 「DNS 失败率」填 100%，为什么还有请求是通的？ | 只拦需要**解析域名**的连接，用 IP 直连的（HTTPDNS、写死 IP）不受影响 |
| 「上行带宽」和「下行带宽」哪一项管「点了没反应」？ | 上行慢 → 请求发不出去；下行慢 → 响应回不来。一次往返 ≈ 上行 + 下行 |
| 带宽是每条连接各一份吗？ | 不是 —— 是**全局共享**的一份，5 条并发连接一起分摊 |

说明文案两端同源（`weaknet.py` 的 `PARAM_NOTES` / `Profile.java` 的 `PARAM_NOTES`），
由 `_t_param_notes.py` 逐条比对，不会出现「电脑上说挂住、手机上说明立刻失败」。

### 限速总开关：启动后默认不运行

打开工具后**不会自动限制任何流量**——状态条里显示「● 未运行」，流量原样转发。必须手动开启：

| 操作 | 结果 |
|---|---|
| 点顶栏的 **「▶ 开启限速」** / APK 的 **「▶ 开始弱网测试」** | 按当前选中的场景开始限速（并接管流量） |
| **直接选一个场景 / 应用自定义参数** | **只是「选中」，不会开始限速**——选中的按钮会高亮，但流量原样转发，必须再点一次上面的开关才生效 |
| 已经在测试中时切场景 | 立即生效（不用停了再开） |
| 点 **「⏹ 停止限速」** / **「⏹ 停止弱网测试」** | 立刻恢复直连；**已选场景会保留**，下次点开启直接复原，不用重选 |

> 这条规矩是刻意改的（2026-10）：早期版本「选一个有内容的场景」就等同于开启限速，
> 结果点一下场景按钮就在没人点开始的情况下把流量限住了。现在**选场景只改「选了哪一支」**，
> 是否真的限速只认总开关。

- 状态灯同步显示「限速未开启 / 限速运行中 / 周期断网中」三态，一眼能看出有没有在限速
- Android 同样默认不动流量：**打开 App 不会自动接管**（早期版本会在启动 600ms 后自动建通道，状态栏白白挂着 VPN 图标却什么都没限），接管与限速都只由「▶ 开始弱网测试」触发；「⏹ 停止弱网测试」会同时断开接管，网络立刻恢复原样
- 接口：`POST /api/run {"enable": true/false}`，状态在 `/api/status` 的 `limit_on` 字段

### 自定义栏（⭐ 我的自定义）

调好一组参数后可以起个名字保存下来，之后像内置预设一样一键切换，不需要了就删掉：

| 操作 | 位置 |
|---|---|
| 保存 | 展开「自定义参数」→ 填名字 → 点「保存当前参数」 |
| 切换 | 点「⭐ 我的自定义」分组里的按钮即可生效（与内置档位同款样式，选中项高亮） |
| 删除 | 先选中那条自定义场景，下方才会出现「🗑 删除当前场景「名字」」按钮（有二次确认弹窗）；选内置场景时按钮自动收起。删除当前生效场景后会切回直连 |

- 自定义场景**不再单独拉一个列表**，保存后就混在「⭐ 我的自定义」分组里，和内置档位长得一样、点起来一样
- 重名自动加序号（如「地铁 5G (2)」），不会静默覆盖旧的那条
- 存储：Windows 写程序目录下的 `weaknet_presets.json`（目录不可写时自动退回 `~/.weaknet/`）；Android 存在 App 私有的 SharedPreferences 里，卸载才丢

对应接口：`GET /api/upresets`（列表）、`POST /api/upreset`（保存 / 按 id 覆盖）、`POST /api/upreset/del`（删除），应用时仍走 `/api/preset`，key 形如 `u:<id>`。

### 弱网组合（📋 组合）

场景解决的是「现在这一秒是什么网络」，组合解决的是「**这一整段测试里网络怎么变**」——
把多支场景按时间轴排成一条，到点自动切换。

一支组合 = **名称 + 循环开关 + 最多 5 段**，每段 = **选一支场景 + 填这段跑多久**。

| 操作 | 位置 |
| --- | --- |
| 新建 | 「📋 组合」标签页 →「➕ 新建」 |
| 编辑 | **长按**组合卡片 → 打开编辑器（新增、删除、重排、换场景、改时长） |
| 删除整支 | 组合卡片上的「🗑 删除当前组合」 |
| 删掉某一段 | 编辑器里**左滑那一行**，会露出红色「删除」按钮 |
| 开始播放 | 点组合卡片**选中**它，再点总开关 **「▶ 开启限速」**（APK 为「▶ 开始弱网测试」） |

举例，「地铁通勤」这支组合可以排成：`4G 弱网 30 秒 → 电梯（完全断网）20 秒 → 4G 弱网 30 秒 → 直连 10 秒`，
勾上循环后每次进电梯都会真实复现一遍断网。

排版与行为上刻意做了这些决定：

- **每段一行**：场景名 + 分 + 秒。场景名是排组合时最需要一眼看清的东西，跟两个输入框抢宽度就会被截成「5G 良…」，反而看不出这段排的是什么
- **场景名点开是一张单选列表**，不是系统下拉框 —— 系统 `Spinner` 在部分 ROM（OPPO / ColorOS 实测）的收起态只画得出下拉箭头，选中的场景名一个字都不显示，展开后的列表里倒是有名字，看着像没选中
- **时长用「分 + 秒」两格**填，单段最长 10 分钟，秒这一格只收 0~59
- **段里不能选另一支组合**：播放是按步骤线性推进的，套一层既不会展开也不会报错，只会在运行时把这一段跳过，用户排的第 2 段凭空消失最难排查
- **新增的一段默认选第一支真正的弱网场景**，不默认「直连」——组合里放直连等于那段时间不做弱网，很容易被当成已经排好了
- **存档引用的自定义场景被删掉后**，编辑器会补一条「已删除的自定义场景」占位并保留原 key，不会趁你一保存就把那一段悄悄换成别的场景
- 走完最后一段：勾了循环就回到第一段继续，没勾就停在直连

对应接口：`GET /api/combos`（列表，含每段 steps 与一行摘要）、`POST /api/combo`（新增/覆盖）、`POST /api/combo/delete`（删除）。

### 接管范围（二级界面）

主界面上是两个并排入口：**「接管一切」**（一键回到全部接管）和**「接管范围」**（打开二级界面勾选）。当前生效的那个会高亮并带 ✔。

只想让一部分走弱网时，点「接管范围」打开二级界面勾选：

| 模式 | 含义 |
|---|---|
| 全部接管 | 全部走弱网（此时勾选列表置灰，勾了也不生效） |
| 仅接管选定项 | 只有勾选的程序 / App 走弱网，其余走真实网络 |
| 排除选定项 | 勾选的不走弱网，其余都走 |

- 二级界面里有搜索、全选 / 清空（只作用于当前筛出来的项）、刷新，以及顶部与底部的返回按钮（Esc 同效）
- 勾选后必须点「保存」才生效；有未保存改动时点返回会先确认，放弃的改动会回滚到引擎当前值
- 「接管一切」已经生效时不再重复提交（Android 端改范围会重建 VPN 通道，重复提交会白白断一次网）

> Windows 按进程名（需该程序发起过网络连接才会出现在列表里），Android 按包名（列已安装应用）。
> 桌面版入口是「接管范围」二级窗口；App 端入口是总开关旁的「指定程序…」。

对应接口：`GET /api/targets`（候选）、`GET·POST /api/scope`（读写名单）。

### 环境共享（局域网互推环境）

同一局域网里开着 WeakNet 的机器会通过 UDP 广播自动互相发现，可以把调好的环境推给对方：

1. 点「⭐ 我的自定义」标题旁的 **「🔗 环境共享」** 打开二级窗口（有未处理的环境时按钮会显示「N 条待处理」）
2. 给自己起个名字（对方看到的就是它）
3. 在「局域网里的设备」里选一台目标
4. 在「我的自定义环境」里勾选要推的场景（可多选）→ 点 **「推送给选中的设备」**
5. 对方若已有同名环境，不会静默覆盖 —— 会进对方的「收到的环境」，由对方决定**覆盖本地 / 保留本地 / 另存为…**（另存默认建议名带推送方，如「地铁3G（来自 乙）」）

- 窗口每 3 秒自动刷新设备与收件箱，**已勾选的对象不会被刷新冲掉**
- 用户名与本机标识存在 `weaknet_settings.json`；标识只生成一次，改名不会换身份（否则对方会看到幽灵设备）
- **默认名字取设备型号**（Android 是 `Build.MODEL`，Windows 是主机名），会随 UDP 广播发给同一局域网的其它设备。介意的话在「环境共享」窗口里改成一个不带个人信息的名字
- 共享端口默认 `8900`，对局域网开放，只认 `/api/hello` 与 `/api/share` 两个路径
- 发现用 UDP `18899` 起的 8 个端口：同机跑多个实例时各占一个，广播时整段都发一份
- 两端都支持环境共享：桌面版入口在「⭐ 我的自定义」标题旁，App 端同样在「⭐ 我的自定义」标题旁。协议一致，Windows ↔ Android 可互推

对应接口：`GET·POST /api/me`、`GET /api/peers`、`POST /api/push`、`GET /api/inbox`、`POST /api/inbox/resolve`。

## 图标

EXE 与 APK 共用一套图形，由 `gen_icon.py` 一处生成：改脚本 → 重跑 → 三处一起变（不会出现「EXE 换了、APK 还是旧的」）。

| 用途 | 文件 |
| --- | --- |
| EXE 文件图标 | `assets/weaknet.ico`（10 档：16/20/24/32/40/48/64/96/128/256，PNG 压缩条目） |
| EXE 窗口 / 任务栏图标 | 以 base64 内嵌在 `weaknet_gui.py`（Tk 默认会挂自己的羽毛图标，这里显式覆盖；内嵌是为了单文件打包不用额外带资源） |
| Android 各密度 | `android/res/mipmap-*/ic_launcher.png`（48 / 72 / 96 / 144 / 192） |
| Android 自适应图标 | `drawable/ic_launcher_{background,foreground}.png` + `mipmap-anydpi-v26/ic_launcher.xml`（前景画在 108dp 画布的中央 70dp 内，圆形/方圆形遮罩都不裁） |

设计：深蓝→靛的圆角方 + 四根白色信号格，**最高那格中间缺了一块**——整体一眼是「网络质量」，缺一块是「弱」。刻意没用闪电（那是测速/加速器的语言），也没用断开的图形（那是「完全断网」，只是本工具的其中一档）。全部粗笔画单色，缩到 16px 任务栏仍能认出是信号格。

```bash
python gen_icon.py            # 生成全部尺寸（需要 Pillow）
python gen_icon.py wave       # 备选方案：W 波形（WeakNet 首字母）
python gen_icon.py --preview  # 只出候选对比图 assets/_icon_preview.png
```
