❓ 使用说明

  1. 电脑端测试：系统设置 → 网络 → 代理，手动配置 127.0.0.1 : 8888；或使用浏览器插件（如 SwitchyOmega）指向该代理。
  2. 手机 App 测试：手机与电脑连同一 Wi-Fi → 点击右上角「开启局域网访问」→ 手机 Wi-Fi 代理设为「手动」，服务器填页面顶部显示的本机局域网 IP，端口 8888（首次开启时 Windows 防火墙弹窗请点允许）。
  3. HTTPS：通过 CONNECT 隧道自动支持，无需安装证书；工具只模拟网络状况，不解密、不篡改内容。
  4. 生效范围：仅对走 HTTP(S) 代理的流量生效；App 若用 TCP 直连 / 私有协议则不经过代理，需在 App 内配置代理，或配合 VPN 类全局转发工具把流量导进来。
  5. 测完恢复：点击「直连（不限制）」或「停止模拟」即可恢复，或直接关闭本工具。
